# oneqode.control

Omarchy bar applet for the OneQode suite. Same job as the KDE tray app,
in the native Quickshell / Omarchy panel language.

Click the bar mark to:

- switch **Light Glass** / **Night Ride**
- toggle solar auto-switching
- set Framework 16 lighting to **Heatmap**, **Solid**, or **Off**
- pick keyboard brightness

Right-click the bar mark toggles Light Glass and Night Ride.

Requires `oneqode-control` on `PATH` (installed by `lib/install-omarchy.sh`).
